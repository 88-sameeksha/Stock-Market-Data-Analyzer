# Industry Relevance

This project demonstrates skills relevant to entry-level Python Developer, Data Analyst, Financial Analyst, Business Analyst, and FinTech roles.

- Python development: modular code, functions, command-line arguments, exception handling.
- Data analytics: cleaning, transformation, descriptive statistics, and CSV exports.
- Financial analytics: returns, moving averages, historical volatility, and drawdown.
- Visualization: price trends, return distributions, and rolling volatility charts.
- Automation: repeatable data processing and report generation.
- Version control: Git and GitHub project organization.

This is an educational portfolio project, not a production trading or investment decision system.
